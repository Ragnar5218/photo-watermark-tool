# 照片水印添加工具 V3.0

一款专业的照片水印添加工具，支持为照片批量添加时间、地点等水印信息。

## 📋 功能特性

- ✅ **批量处理**: 支持对整个文件夹中的照片进行批量水印添加
- ✅ **两种时间模式**:
  - **使用拍摄时间**: 从照片的EXIF信息中读取拍摄时间
  - **使用自定义时间**: 在指定时间范围内随机生成时间
- ✅ **自定义地点**: 支持输入自定义地点名称
- ✅ **水印内容**:
  - 时间（年、月、日、时、分）
  - 地点名称
  - 星期信息
- ✅ **处理控制**:
  - 开始添加：启动水印添加过程
  - 暂停：暂时停止处理
  - 继续：从暂停处恢复处理
  - 停止：完全停止处理
- ✅ **实时进度显示**: 显示处理进度和状态信息
- ✅ **处理日志**: 记录详细的处理过程

## 📖 使用教程

### 基本操作步骤

1. **选择照片文件夹**
   - 点击"浏览"按钮，选择包含照片的文件夹
   - 支持的图片格式：PNG、JPG、JPEG、BMP、GIF

2. **输入地点名称**
   - 在"地点名称"输入框中输入地点信息
   - 例如：北京故宫、上海外滩、三亚海滩

3. **选择时间模式**
   - **使用拍摄时间**: 从照片的EXIF信息中读取原始拍摄时间
   - **使用自定义时间**: 手动指定日期和时间范围，程序会在该范围内随机生成时间

4. **设置自定义时间（可选）**
   - 如果选择"使用自定义时间"，需要设置：
     - 选择日期
     - 设置最早时间（开始时间）
     - 设置最晚时间（结束时间）

5. **开始处理**
   - 点击"开始添加"按钮启动处理
   - 可以随时点击"暂停"暂停处理
   - 点击"继续"恢复处理
   - 点击"停止"完全停止处理

## 🐛 常见问题

### Q1: 程序无法运行，提示缺少DLL文件？

**解决方案**: 确保您的系统已安装最新的Visual C++运行库。

### Q2: 照片没有EXIF信息怎么办？

**解决方案**: 如果照片没有EXIF信息，程序会自动使用文件的创建时间作为拍摄时间。

### Q3: 水印文字太小/太大怎么办？

**解决方案**: 水印大小会根据照片尺寸自动调整。如果需要自定义大小，可以修改源代码中的 `watermark_height_ratio` 参数。

### Q4: 处理过程中出现错误怎么办？

**解决方案**: 
1. 检查照片文件是否损坏
2. 确保有足够的磁盘空间
3. 检查文件权限是否正确

### Q5: 程序突然崩溃怎么办？

**解决方案**: 
1. 检查照片文件夹中是否有非图片文件
2. 尝试分批处理照片
3. 确保照片格式正确
