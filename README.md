# 照片水印添加工具 V3.1

> 一款简洁专业的批量照片水印工具，自动读取照片拍摄时间并叠加时间、地点、星期水印，支持苹果 HEIC 格式。

---

## ✨ 功能特性

- **批量处理**：递归扫描文件夹中的所有照片，一键批量添加水印
- **拍摄时间自动识别**：从 EXIF 读取照片原始拍摄时间，兼容 JPG / PNG / HEIC 等格式
- **苹果 HEIC 支持**：直接读取 HEIC/HEIF 照片，处理后自动转换为 JPG 保存
- **双时间模式**：
  - 使用拍摄时间（默认）
  - 自定义时间区间（在指定时间段内随机分配时间）
- **水印内容**：时间（`2026-10-07 17:06` 格式）、地点、星期
- **水印颜色**：10 种预设颜色 + 自定义取色器
- **水印尺寸自适应**：根据图片尺寸自动计算水印大小
- **处理控制**：支持开始 / 暂停 / 继续 / 停止
- **进度与日志**：实时进度条 + 详细处理日志
- **授权管理**：内置试用与注册激活机制

---

## 📸 支持的图片格式

| 格式 | 说明 |
|------|------|
| JPG / JPEG | 主流相机格式，完整 EXIF 支持 |
| PNG | 无损压缩格式 |
| BMP | 位图格式 |
| GIF | 动图格式（取首帧） |
| **HEIC / HEIF** | 苹果照片格式，自动转 JPG 保存 |

## 🚀 快速开始

### 方式一：直接运行 EXE（推荐）

1. 下载 `照片水印工具.exe`
2. 双击运行，无需安装 Python 环境

### 方式二：运行源码

**环境要求：** Python 3.8+

```bash
# 1. 安装依赖
pip install PyQt5 Pillow pillow-heif

# 2. 运行程序
python 照片水印工具-合并版.py
```

> ⚠️ 注意：需使用安装了上述依赖的 Python 环境运行。

## 📖 使用说明

1. **选择文件夹**：点击「浏览」选择需要添加水印的照片文件夹（支持递归子目录）
2. **输入地点**：填写地点名称，例如「北京故宫」
3. **选择水印颜色**：点击预设颜色块或「选择颜色」自定义
4. **选择时间模式**：
   - 「使用拍摄时间」：自动读取照片 EXIF 中的拍摄时间
   - 「使用自定义时间」：设置日期与时间区间，程序随机分配
5. **开始添加**：点击「开始添加」按钮，等待处理完成

## 🔧 水印效果示例

水印位于照片左下角，包含三行信息：

```

地点：北京故宫
备注：星期三
```

- 中文使用宋体，数字/字母使用 Times New Roman
- 水印大小根据图片尺寸自适应
